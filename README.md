# mini-project

다이빙 기록 서비스 `GANI Log`의 화면 시안을 정리한 프로젝트입니다.

## 현재 상태

`files` 폴더에 로그인, 회원가입, 기기 연동, 로그 작성, 대시보드, 로그 목록·상세, 장비 관리, 내 정보 화면의 정적 HTML 시안이 있습니다.

## 확인 방법

`files/index.html`을 웹 브라우저로 열면 9개 화면을 한 페이지에서 확인할 수 있습니다. 로컬 웹 서버에서 `files/1-로그인.html`을 열면 로그인부터 주요 화면 이동을 서비스 흐름처럼 확인할 수 있습니다.

화면 이동은 `prototype.js`로 연결되어 있습니다. 로그 작성은 연동 데이터 확인, 추가 정보 입력, 최종 확인과 로컬 저장까지 4단계로 이어집니다. 내 정보 화면에서는 이름, 이메일, 다이빙 자격을 수정할 수 있고, 장비 관리 화면에서는 이름과 종류, 종류별 세부 분류를 선택해 장비를 등록할 수 있습니다. 입력한 값은 현재 브라우저의 로컬 저장소에 보관됩니다. 실제 인증, 서버 데이터 저장, 검색, 기기 연동 기능은 구현되지 않았습니다.

## 변경 기록

자동 업로드된 변경 내역은 [`AUTO_CHANGELOG.md`](./AUTO_CHANGELOG.md)에서 확인할 수 있습니다. 코드의 실제 변경 내용은 GitHub 커밋의 diff에 기록됩니다.
